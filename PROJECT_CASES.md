# Кейсы и материалы

Изменены только работы и управление проектами. Семь кейсов из пакета добавлены перед прежними проектами; прежние проекты и настройки сохранены. Обложки — концепты, не реальные скриншоты. К каждому кейсу приложено текстовое описание для скачивания. Реальных дополнительных фотографий во вложениях нет: их можно загрузить через редактор.

Редактор поддерживает обложку, задачу, решение, результат, необязательную внешнюю ссылку и до 20 материалов в заданном порядке. Изображения JPG/PNG/WebP уменьшаются до 1200 px; документы PDF/TXT/DOCX/XLSX/PPTX до 250 КБ сохраняются без изменения. Материалы хранятся в site.json и доступны публично. Общий лимит публикации — 900 КБ. При превышении размера прежний черновик сохраняется. Экспорт/импорт включают материалы.

## Обновление действующего Google Apps Script

Перед работой с новыми кейсами через админку замените код в редакторе Google Apps Script содержимым `google-apps-script/Code.gs`, затем «Управление развёртываниями → Изменить → Новая версия → Развернуть». Сохраните прежний URL, свойства, авторизацию и таблицу. Не запускайте setup и не сбрасывайте пароль. Изменён только валидатор проектов; обработчики заявок и уведомлений сохранены.

Отправка исходников в GitHub не обновляет развёртывание Google автоматически. До обновления валидатор старого сервера не принимает новые категории. Реальная авторизованная публикация в Google не проверялась: проверки используют существующий Apps Script harness без отправки заявок и уведомлений.

## Проверки

`npm run check` и `npm test` (9 тестов).

`node tests/browser-cases.cjs` — Chromium/Playwright; путь Chromium задаётся в тесте. Проверяет загрузку изображения и документа, подпись, порядок, сохранение, публикацию через настоящий Code.gs с заменами внешних сервисов, скачивание и ширины 1440/1024/390/360/320. Не использует реальные учётные данные и не пишет в Google/GitHub.
