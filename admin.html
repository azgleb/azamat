Из черновика — на сайт

Панель сохраняет тексты и проекты в файл site.json в GitHub. После коммита GitHub Pages обновит сайт, обычно за несколько минут. Токен нужен только владельцу; посетители не могут изменять опубликованные данные.

  1. Создайте fine-grained token на GitHub. Выберите только репозиторий сайта, разрешение Contents: Read and write и срок действия.
  2. Введите токен здесь и подключите репозиторий. Токен остаётся только в памяти вкладки и отправляется исключительно в api.github.com.
  3. Проверьте предпросмотр и нажмите «Опубликовать».
