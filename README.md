# Портфолио Азамата

Минималистичный адаптивный сайт без зависимостей. Требуется Node.js 18 или новее.

## Запуск

```sh
cd /workspace/azamat
npm start
```

Сервер слушает порт 3000 на всех интерфейсах. Порт можно изменить переменной `PORT`. `npm run check` проверяет синтаксис JavaScript.

## Проекты

Нажмите «Добавить проект», заполните название, категорию, год и описание; при желании добавьте ссылку и обложку (JPG, PNG, WebP до 3 МБ). Карточка открывает подробности и удаление с подтверждением. Фильтры переключают категории.

Данные хранятся в localStorage текущего браузера и адреса сайта. Они не публикуются для других посетителей и могут исчезнуть при очистке браузера. Экспортируйте JSON для резервного копирования; импорт заменяет коллекцию после подтверждения. Это локальный прототип: для общей публикации проектов и входа владельца нужен сервер хранения и авторизация.

Начальная коллекция содержит четыре демонстрационных проекта. Замените их своими. Тексты о себе, имя и контакты редактируются в `index.html`; стили — в `style.css`. Шрифт Manrope загружается из Google Fonts; без сети используется Arial.
