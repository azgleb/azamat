# Azamat Works — портфолио

Минималистичный адаптивный сайт: проекты, защищённая админ-панель и заявки в Google Таблице.

## Запуск

Нужен Node.js 18+. Выполните `npm start`; сервер слушает порт 3000 (`PORT` меняет порт). `npm run check` проверяет синтаксис, `npm test` запускает серверные тесты с заменами сервисов Google/GitHub. Для GitHub Pages сборка не нужна — статические страницы публикуются из корня ветки `main`.

## Подключить заявки и вход

**[Пошаговая инструкция Google Apps Script](google-apps-script/SETUP.md).**

Создайте проект Apps Script со скриптом из `google-apps-script/Code.gs`, задайте приватные свойства и выполните `setup`. Он создаст закрытую Google Таблицу и сгенерирует логин/пароль для владельца. Разверните как веб-приложение и сохраните публичный `/exec` URL в `backend-config.js`.

До подключения сервера форма честно сообщает, что приём заявок ещё не работает, а админ-панель остаётся закрытой. Наличие кода не означает развёртывание сервиса в Google.

## Уведомления о новых заявках

Email и Telegram подключаются отдельно или одновременно через закрытые свойства Apps Script. [Инструкция](google-apps-script/SETUP.md#уведомления-на-телефон-почта-и-telegram). Уведомления содержат данные заявки и ссылку на таблицу; результат доставки записывается в колонку «Уведомления». Ошибка доставки не теряет сохранённую заявку. Реальные отправки требуют настройки аккаунта владельца и здесь не выполнялись.

## Что можно делать

- Посетители: смотреть проекты, фильтровать категории, читать подробности, отправлять имя, контакт и описание задачи через форму в разделе «Давайте создадим что-то хорошее».
- Владелец после входа: добавлять, редактировать, скрывать, удалять и переставлять проекты; загружать обложки; менять имя, заголовки, тексты, навыки и контакты; просматривать последние 100 заявок и менять их статусы.
- Черновик сохраняется в текущем браузере. Предпросмотр виден только в этом браузере. «Опубликовать изменения» обновляет `site.json` в GitHub через сервер. Изменения для посетителей появятся после обновления GitHub Pages.
- Экспорт и импорт резервных копий. Старые проекты из localStorage можно перенести в черновик, если сохранились прежние адрес и браузер.

## Защита и хранение

Пароль проверяется только в Apps Script, хранится там в виде соли и хеша. Поддерживается сгенерированный длинный пароль с высокой энтропией. GitHub-токен хранится в приватных свойствах скрипта и не приходит в браузер. Сессия держится в памяти вкладки до часа, может завершиться раньше из-за очистки кеша Google; обновление страницы требует повторного входа. Сервер проверяет сессию для заявок и публикации, ограничивает попытки входа. Выход отзывает сессию, смена пароля отзывает все сессии.

HTML панели публичен, но это не даёт прав на серверные операции. Заявки находятся в приватной Google Таблице, не в GitHub и не в localStorage. При повторе отправки после сбоя сети ID заявки сохраняется, сервер не добавляет дубликат. Есть валидация, базовые ограничения частоты, поле-ловушка и защита от формул в таблице. При массовом спаме потребуется усиление защиты; также действуют квоты Google.

Все тексты и проекты в `site.json`, включая скрытые, доступны в публичном репозитории и истории Git. Не помещайте туда конфиденциальные данные. Обложки автоматически уменьшаются до 1200 px, JPEG; лимит одной обложки в data URL — 450 КБ, файла публикации — 900 КБ.

Шрифт Manrope загружается из Google Fonts, без него используется системный шрифт. В настройках DNS, GitHub Pages или исходном CSS панель ничего не меняет.

## Проверено

Восемь автоматических серверных тестов (включая уведомления, независимость каналов, обработку ошибок и отсутствие повторной отправки): запрет анонимных административных операций; пароль/сессии/выход/сброс; ограничение попыток входа; валидация и безопасная запись заявок без дубликатов; ограничение частоты; публикация с защитой от конфликта версий.

В Chromium проверены форма и повтор после потерянного ответа, неверный/верный пароль, заявки и статусы, публикация через сервер, истечение сессии и выход, отсутствие пароля в хранилище, мобильная ширина и закрытый доступ при неподключённом сервере. Google Sheets, CacheService и GitHub API в этих тестах заменены тестовыми реализациями. Проверка реального Google-развёртывания и записи в таблицу ещё требуется после настройки аккаунта владельца.
